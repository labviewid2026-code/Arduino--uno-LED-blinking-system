# Arduino Uno LED Blinking System

## Project Overview
The Arduino Uno LED Blinking System is a basic electronics and embedded programming project designed to demonstrate how an Arduino Uno controls an LED through a digital output pin. The LED continuously turns ON and OFF at specified time intervals using simple Arduino code.

## Components Required
- Arduino Uno
- LED
- Resistor (220Ω or 330Ω)
- Breadboard
- Jumper wires
- USB cable

## Working Principle
The Arduino Uno sends HIGH and LOW signals through a digital pin to control the LED.

- **HIGH:** LED turns ON.
- **LOW:** LED turns OFF.
- **Delay:** Controls the time interval between ON and OFF states.

The program runs continuously, creating a blinking effect.
